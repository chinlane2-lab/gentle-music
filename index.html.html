Important: This connects directly to Google only after you set up your own Google Cloud OAuth Client ID and API key, then approve access. I cannot sign in to your account or receive your credentials for you. Free YouTube playback may still contain ads; this app cannot remove them.
Step 1 · Connect your Google / YouTube account

One-time setup: in Google Cloud Console, create a project, enable YouTube Data API v3, configure OAuth consent, and create an OAuth client ID for a Web application. Add this page's origin as an authorised JavaScript origin (when hosted), or use a local testing origin/server. Create an API key and restrict it to YouTube Data API v3 and your site.
